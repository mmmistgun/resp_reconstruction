# PATCH/TM0/REF0 主模型：消融、拓展与额外模型设计

创建：2026-09-29；更新：2026-09-30。状态：**研究设计已落实为13臂、39-cell统一实现，工程验证与执行规则见[统一训练协议](patch_apor_v1_protocol_20260930.md)。**

依据用户本次决定，后续研究以 `PATCH/TM0/REF0` 为主模型，本文暂称 **P0**，对应 `sfv1_patch_tm0_ref0`。这里的 P0 是模型简称，与历史协议的 P0 阶段无关。历史 W0 及各结项的模型身份和结果保留原义；本文件不修改既有冻结表、checkpoint 或协议。

## 1. 主模型定位与证据起点

研究主线建议为：**从床体机械信号中重建兼顾呼吸节律、波形形态和相对幅度变化的 THO 参考波形，通过紧凑的时频条件结构减少额外时间处理。**

任务仍为既有 BCG 输入到 THO 参考的 180 s、100 Hz 重建，外置 `Pi=S(B_0.05–0.70Hz(.))`、完整 loss、五指标和 selector 保持既有定义。THO 相对幅度不直接等同于绝对通气量或经标定的呼吸肌做功。

P0 保留 Patch 编码、六层 D96 双向 Mamba2、97-scale CWT 二维编码、scale mean、H65 条件末端、post-trunk FiLM、原 coarse head 和 C201 decoder residual。TM0 删除 CWT 尺度聚合后的三层一维时间块；REF0 删除 FiLM 后的两层 refinement。二维编码器和读出仍含时间卷积。

同轮 W0 三因素实验的三 seed 均值如下，不能用其他轮 W0 的更好或更差数值替换同轮对照：

| Split / 模型 | Whole RR | Local RR | 包络轨迹 | 全局调制 | PCC |
|---|---:|---:|---:|---:|---:|
| Validation 完整 W0 | 0.497327 | 0.551939 | 0.152166 | 0.187206 | 0.863919 |
| Validation P0 | 0.501902 | 0.550870 | 0.147635 | 0.179050 | 0.863949 |
| Research-test 完整 W0 | 0.637269 | 0.611730 | 0.140746 | 0.175462 | 0.873767 |
| Research-test P0 | 0.670981 | 0.630742 | 0.139557 | 0.165216 | 0.878331 |

P0 参数为 1,031,690，比完整 W0 少 15.43%。已有 cached-input benchmark 的训练吞吐提高 10.57%，不含 CWT 生成。协议的 factor-covered MACs 减少 98.91%，不是完整网络计算量减少 98.91%。

P0 的选择体现波形重建与效率的研究优先级。Research-test 的 Whole/Local RR 相对完整 W0 增加 0.033712/0.019011 bpm；目前没有证明它在所有属性上支配完整 W0。原先以 RR 为最高优先级的论文定位需在后续新版本中明确更新。本次选型已知历史 research-test，后续不能将同一 split 描述为未参与模型设计的独立确认。

来源：[W0 三因素结项](w0_structural_factorial_v1_closeout_20260925.md)、[真实计算图及训练合同](w0_structural_factorial_v1_protocol_20260923.md)。本次阅读代码和记录，未重新核验全部运行产物哈希。

## 3. 建议的主模型消融矩阵

### 3.1 已有结构表：新增训练为零

主表呈现 P0、P0+TM3、P0+REF2、P0+TM3+REF2；保留全八臂附表和交互结果。前端表使用同轮 PATCH/TM0/REF0 与 CONV20/TM0/REF0，解释为两个完整前端 package 的比较。

这些结果回答“额外时间处理是否值得保留”，不推出“时间建模无用”：P0 的双向 Mamba、二维时间核与 decoder 时间卷积都仍然存在。

### 3.2 第一优先级：六臂模块消融，6×3 seed=18 次训练

每个变体只改变下表指定的模块，均相对 M0 独立比较。完整训练目标、前处理、其余模块和 selector 固定；删除模块后的自然参数量和实际计算成本作为结果报告。

| ID | 模块 | 精确操作 | 研究问题 |
|---|---|---|---|
| M0 | 完整 P0 | 同合同从头训练锚点，独立运行身份 | 主模型基准 |
| M1 | CWT 条件分支 | 删除 W 分支与 FiLM，trunk 输出直接进入原 head | CWT 条件路径对波形重建的总贡献 |
| M2 | 六层 BiMamba2 主干 | 整个 block stack 替换为 Identity，保留 Patch frontend、FiLM 与原 head | 序列主干在局部编码之外的增量作用 |
| M3 | CWT 尺度邻域编码 | 首层核 (5,3)→(1,3)，depthwise 核 (3,3)→(1,3)，尺度 padding→0 | 相邻尺度交互是否有用 |
| M4 | H65 条件末端 | residual 96→65→96 替换为 Identity，保留最终 gamma/beta 投影 | 条件进入 FiLM 前的通道残差重组是否必要 |
| M5 | C201 解码残差 | 删除 32→32→1 nonlinear residual，保留 base head、时间卷积与 Fourier 插值 | 额外非线性读出对局部形态的贡献 |

M2 仍含 PatchMixer、CWT 时间卷积、读出卷积以及跨时间统计的 GN，因此解释为“移除 BiMamba2 主干”，不命名为“无时间信息”。M3 的时间核宽度、通道数、GN、激活、scale mean 和插值保持一致；它研究尺度邻域卷积，不代表删除整个 CWT encoder。M4 中 H65 残差两端均为96通道，Identity不需要新增适配。M5与E8整体decoder替换不同，只切除现有非线性残差支路。

共享模块按命名 seed 初始化，并核对可共享参数；结构替换不会改变其他模块的随机初始化。全部模型从头训练；不能用完整模型的推理期关模块代替该表。

### 3.3 第二优先级：FiLM 路径设计，追加2臂×3 seed=6次训练

| ID | 结构 | 公式 | 研究问题 |
|---|---|---|---|
| M0 | 完整 FiLM | z'=z⊙(1+g)+b | 乘性与加性条件共同作用 |
| M6 | 加性条件 | z'=z+b | 仅条件偏移是否足够 |
| M7 | 乘性条件 | z'=z⊙(1+g) | 仅条件增益是否足够 |

保留完整 W encoder 和 H65；M6/M7 将最终投影改为对应96通道，并分别使用M0的beta/gamma初始化切片。保留原0.5*tanh界限和零初始化，不注册未使用输出。FiLM位置固定在主干后。该组与M1联合区分“条件分支是否有用”和“怎样注入条件更合适”。已有P5的冻结路径干预只作研究依据。

### 3.4 固定 checkpoint 的小型机制矩阵

在 M0 的三个固定 validation checkpoint 上比较 FULL、CONDITION_OFF、GAMMA_ONLY、BETA_ONLY、TIME_MEAN、TIME_SHIFT(+30 s)、TIME_SHIFT(−30 s)。共 7 条件×3 checkpoints，新增训练为零，但属于待授权的真实 validation 推理。

时间错位首轮作用于编码后、FiLM 投影前的条件序列，以减少输入 GN 统计变化的混淆；它回答条件时间对应的功能依赖。R3 输入机制另立小矩阵，复用 E4 的固定 GN 与分布保持控制。二者不混称为同一干预。所有操作按同一窗口、同一 checkpoint 配对，先验证 FULL 重放；干预和重训练证据分别报告。

## 4. 拓展实验及优先顺序

1. **适用范围与尾部。** 首先使用既有 P0 validation 逐窗口指标，做 subject/session、既有 RR 区间、THO 相对包络变化、Local RR P90/P95 与 >2/>5 bpm 分析。RR 正确但形态/幅度失真的比例沿用 E3 思路，新阈值只用预先声明的 validation 参照固定。不把目标包络低直接命名为临床呼吸暂停，也不根据模型误差选择展示样本。
2. **输入扰动稳健性。** 预注册增益 0.5/1/2、加性噪声 SNR 20/10 dB、短时缺失 0.5/1/2 s 的独立单因素曲线，完整 target 和分母保持固定。第一版定义为 soft-z 之后的模型输入敏感性；如需模拟传感器变化，则在原信号层扰动并重走前处理，另设身份。每次都从同一扰动 x 重算 W，避免 raw/CWT 两视图不一致。合成扰动不等同于真实跨设备泛化。
3. **完整管线效率。** 在同硬件、相同 batch 和精度下比较 P0/完整 W0/额外模型，分别测 raw→CWT→模型→输出总时延和 cached-input 模型时延，报告 median/P95、peak memory、参数和缓存成本。双向主干属于离线窗处理；180 s 的窗口可用性与计算时间分开报告。
4. **独立人群或外部确认。** 在模型、比较矩阵和判定标准冻结后进行，优先于继续在当前 research-test 上挑结构。尚无合适外部数据时，可以另设按 subject/session 分组的 train 内验证设计；它能检验组间稳定性，但不能消除既往全数据开发知情历史，也不能冒称新的独立最终测试。

## 5. 额外模型：时间坐标对齐的 Patch 重叠重建网络

暂称 **Aligned Patch Overlap Reconstruction（APOR）**。这是拟研究结构，不预设精度、速度或文献新颖性。

### 5.1 信号、任务与结构动机

- **信号：**床体机械信号既包含较慢的呼吸运动，也可能包含受呼吸调制的较快机械形态。保留原始 patch 内的有符号波形和 CWT 条件，比强行把输出约束为规则正弦更符合完整波形任务。呼吸相关变化不能统一归结为纯幅度调制。
- **任务：**需要恢复局部形态与幅度变化，而不是只给一个 RR；每个 token 解码一段有符号波形，再按真实采样位置重叠合成。
- **模型：**目前 Patch 前端先产生 140 个 token，再线性插值成 1800 点进入六层 Mamba。APOR 在原生 140-token 序列上建模，检验密集插值后主干的必要性，同时显式建立 Patch/CWT 时间坐标。

已有原始研究支持床体信号的呼吸成分和呼吸相关机械形态变化：[Alihanka 等，1981](https://journals.physiology.org/doi/pdf/10.1152/ajpregu.1981.240.5.r384)、[Paalasmaa，2010](https://pubmed.ncbi.nlm.nih.gov/20720287/)。它们为结构假设提供动机，不证明本仓库具体频带来源。后者指出纯幅度调制不足以描述全部变化。

### 5.2 拟定计算图

```text
x [B,1,18000]
  → 原 Patch(L256,S128) + 两层 PatchMixer
  → [B,16,140] → adapter/GN/SiLU → [B,96,140]
  → 六层双向 Mamba2 → Z [B,96,140]

原 97-scale CWT [B,97,360]
  → 原浅层二维编码 + scale mean → C [B,96,360]
  → 每个 patch 支撑区间内按物理坐标取五个条件向量
  → concat [B,480,140] → Linear(480,96)
  → H65 条件末端 → bounded FiLM → 调制 Z

调制 Z → 逐 token MLP(96→96→256)
  → 140 段有符号、256 点局部波形
  → 正权重 overlap-add(S128) → 裁回18000点 raw waveform
  → 外置原 Pi / 原 loss / 原指标
```

不添加 TM3/REF2。MLP 的激活建议固定 SiLU，末端线性输出。原 coarse head/C201 残差/Fourier 上采样由局部 patch decoder 整体替换；因此 APOR 是新模型 package，不登记为 P0 的单模块消融。参数量、MACs 和实际时延须实现后测量。

时间坐标定义：第 j 个 patch 起点 `128j/100` s，中心 `(128j+127.5)/100` s；CWT 每50点均值的中心为 `(50k+24.5)/100` s。五个条件位置取 patch 内相对采样坐标 `0、63.75、127.5、191.25、255`，在 CWT 特征时间轴上线性采样，边界固定为最近有效值延拓。最后 patch 的原始输入继续右补48点零，并在输出裁剪时剔除；不新增虚构 target。

五个条件位置用于保留 patch 内条件变化，480→96投影将该局部条件片段编码为一个向量。采样没有增加真实观测或提高CWT的2-Hz采样率。五点是首版设计选择，作用由中心单点变体检验。

合成公式：

`y[n] = sum_j w[n−128j] * p_j[n−128j] / sum_j w[n−128j]`。

采用仓库已有 clamp-min=1e-3 的 Hann 权重定义，保证首尾分母严格为正。实现可使用向量化 fold，但先用简单参考实现验证一致性。

### 5.3 完整模型与模块级设计实验

完整APOR作为独立模型A0，用相同数据、loss、selector与三seed训练，与M0/P0比较完整五指标和效率。该比较回答整体结构是否值得采用，不把整体变化拆成未经验证的模块收益。

围绕A0设置四个独立模块变体，每臂从A0定义出发，其他模块固定，整体纳入统一训练矩阵：

| ID | 模块 | 操作 | 研究问题 |
|---|---|---|---|
| A0 | 完整APOR | 140-token主干＋五点条件＋非线性Patch解码＋Hann重叠合成 | 新模型基准 |
| A1 | Patch条件采样模块 | 五点concat/480→96改为中心单点/96→96，H65与FiLM不变 | Patch内条件变化是否提供增量作用 |
| A2 | 局部波形解码模块 | MLP(96→96→256)改为Linear(96→256)，重叠合成不变 | 局部解码非线性的作用 |
| A3 | 主干时间网格 | 将16通道Patch特征按真实坐标插值到1800点，再运行原adapter与六层主干，主干后按真实Patch中心采回140点；条件、FiLM和decoder与A0相同 | 密集时间网格上的序列处理是否值得其成本 |
| A4 | 重叠合成权重 | Hann改为uniform，片段长度与步长保持一致 | 合成加权对局部接缝与波形形态的作用 |

A0–A4共15次训练。A3维持Patch中心坐标和边界规则，波形插值发生在adapter/GN前，回采样发生在FiLM前。网格改变也影响Mamba局部卷积的物理时间跨度与GN统计，按“主干时间网格设计”解释结果。A1按模块自然尺寸构建，其结果回答单点与局部片段条件编码的结构差异。

A4检验加权方式，不能证明重叠本身的作用。改变stride或取消重叠会同时改变token数量、输入覆盖及解码拼接，需独立设计。

### 5.4 必须先检验的风险与成功条件

1. 140/180≈0.78 token/s，**不能**让每个 token 只输出一个标量再插值，声称覆盖0.70 Hz；这里的每个 token 是多维向量，并解码256点局部波形。该设计缓解标量采样瓶颈，但仍须在接近任务上界的频率、变频和非正弦 synthetic fixture 上检验信息保存。
2. 140 token 主干相对1800减少约92.2%的序列位置，但 Mamba padding/kernel、小序列利用率、decoder 与 CWT 开销会影响实际收益，不能称为92.2%端到端加速。
3. 在低幅度、包络突变、呼吸节律变化以及首尾/patch接缝区域检查误差；overlap-add 是合成规则，不自动保证生理相位正确或接缝平滑。
4. 继续完整五指标与原 Local RR selector。结果分类为质量改善、效率取舍或不支持；非劣界需在正式运行前声明，现有描述性容差不等同于统计非劣检验。
5. Patch 解码与 overlap-add 在 `resp_train/models/timeseries.py` 的既有 PatchMixer 中已存在。新增研究问题是原生 Patch 主干、物理坐标条件对齐与完整波形合成的组合，不把基础算子重新命名为原创。

## 6. 执行合同与投入安排

M0–M7共24次、A0–A4共15次，统一纳入 **39-cell训练矩阵**，配置与模块定义在同一session中固定。调度入口依次完成工程验收、全部训练与validation汇总；不依据partial seed删改候选。GPU时间须以实际测量估计。
