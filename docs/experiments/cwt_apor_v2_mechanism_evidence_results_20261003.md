# CWT-APOR v2机制证据整理结果

日期：2026-10-03。状态：用户指定的TF-S1调制谱、FiLM案例路径、受试者差异三项整理已完成。本文为既存产物的事后探索性分析；方法见[分析约定](cwt_apor_v2_mechanism_evidence_analysis_20261003.md)，完整机制评价身份见[机制完成记录](cwt_apor_v2_mechanisms_results_20261002.md)。

本轮证据支持一条清楚的解释：高频CWT通道的时间变化中包含与呼吸包络对应的成分，APOR通过条件分支改变FiLM系数与潜在特征；破坏高频时间对应关系会在全部8名test受试者中增加平均包络误差。RR对干预的响应高度不均匀，主要集中于670，且与谱峰竞争和既有质量标签相关。

## 1. 高频载频通道携带什么慢变化

TF-S1使用C_20条件序列的既存PSD：train为10141窗/32人，validation为2675窗/7人。每窗、每尺度去除DC后归一化，先平均受试者内窗口，再对受试者等权平均；载频分段内尺度等权。频率分辨率为1/180 Hz。

**CWT载频**描述原信号中的振荡频段；**调制频率**描述这些CWT条件通道随时间变化的速度。下表的0.05–0.70 Hz指后者。

| CWT载频 | 0.05–0.70 Hz调制功率比例 train / val | FULL包络相关 train / val | FULL−SHIFT包络相关 train / val |
|---|---:|---:|---:|
| 0.03–0.8 Hz | 7.15% / 7.07% | 0.0269 / 0.0377 | +0.0333 / +0.0424 |
| (0.8,2] Hz | 52.52% / 54.43% | 0.2357 / 0.2306 | +0.2504 / +0.2565 |
| (2,4] Hz | 68.10% / 69.50% | 0.2639 / 0.2718 | +0.2758 / +0.2966 |
| (4,8] Hz | 66.57% / 70.26% | 0.2599 / 0.2461 | +0.2710 / +0.2712 |
| (8,12] Hz | 61.41% / 64.82% | 0.2039 / 0.1853 | +0.2132 / +0.2022 |
| (12,20] Hz | 62.11% / 62.91% | 0.1901 / 0.2171 | +0.2003 / +0.2411 |

关联沿用原流程：条件序列先投影到0.05–0.70 Hz，再计算10秒log-RMS包络，与参考呼吸包络作零时滞关联；SHIFT为三个预设平移的平均。它检验的是这些变化成分的包络对应关系。

在(0.8,2]、(2,4]、(4,8]三个载频段，32/32名train受试者和7/7名validation受试者的FULL−SHIFT包络相关均为正。2–8 Hz通道兼具较高的呼吸尺度调制功率和稳定的包络对应关系，与A0的高频错位干预结果相互衔接。8–20 Hz是C_20信号诊断的扩展范围，A0机制干预的H上限仍为8 Hz。

原边界裁切使最低4个尺度的包络相关无法定义，分段关联只包含52/56个低频尺度；其余分段全部尺度有效。逐尺度文件保留有效受试者数、窗口数和缺失原因。

已有表格支持0.05–0.70 Hz调制带整体的关联，无法进一步确定其中哪个窄频段贡献最大。PSD比例也受CWT时间分辨率与池化影响，不能直接解释为信息贡献率或模型的重要性权重。

## 2. FiLM路径发生了什么变化

遍历全部三个seed、每seed24个预定窗口、18个条件，共1296份案例记录。三个PDF图册各24页，逐例对齐FULL、H-SHIFT1自然GN、H-SHIFT1固定GN的条件CWT、γ/β变化、`Z′−Z`、配对`ΔZ′`、预测包络与逐点误差。全部SHIFT与均值替换条件的量化记录保留在CSV中。

三个H-SHIFT、三个seed和24个预定窗口的描述性平均如下；数值分别使用各张量自身单位，不能跨行直接比较重要性。

| 路径量 | 自然GN | 固定GN |
|---|---:|---:|
| RMS(Δγraw) | 0.563766 | 0.564531 |
| RMS(Δβraw) | 0.539811 | 0.540492 |
| RMS(Δg)，g=0.5 tanh(γraw) | 0.127587 | 0.127891 |
| RMS(Δb)，b=0.5 tanh(βraw) | 0.131495 | 0.131702 |
| RMS(ΔZ′) | 0.229722 | 0.230096 |
| 预测中心化log-RMS包络的配对绝对差 | 0.070597 | 0.070774 |

所有案例的公共Z与参考信号在条件间逐点相同。FULL/FIXED与FULL/NAT的路径变化和两项误差差值均为0。H错位改变了γ/β和调制后的潜在特征，并传递到预测包络；固定GN后变化仍保留。`Δg·Z+Δb`与实际`ΔZ′`的平均RMS残差为0.002948，符合导出中存在BF16舍入的情况，不能将该等式当作精确的中介效应分解。

**预定案例与总体效应必须分别解读。** 三个SHIFT和三个seed平均后，24例中15例包络误差增加，但24例均值为−0.002433；完整2310窗均值为+0.003361。首/中/末窗口组成的案例集不代表总体分布。图册提供传递路径的可读解释，误差增减结论由完整配对表支撑；不从案例中重新挑选“符合方向”的子集。

## 3. 包络效应覆盖全部受试者，RR效应集中于670

以下以机制同流程FULL/NAT为基准，先平均三个预设H-SHIFT与三个seed，再在各受试者内平均；正值表示误差增加。

| 受试者 | 窗口数 | 包络MAE变化 | 窗口包络退化比例 | FULL RR MAE（bpm） | RR MAE变化（bpm） |
|---|---:|---:|---:|---:|---:|
| 220 | 283 | +0.003528 | 64.66% | 0.415914 | +0.011968 |
| 229 | 298 | +0.001578 | 54.36% | 0.160576 | +0.001184 |
| 286 | 302 | +0.003003 | 69.21% | 0.352290 | +0.028940 |
| 670 | 79 | +0.016811 | 68.35% | 6.426940 | +1.122267 |
| 671 | 504 | +0.001806 | 64.29% | 0.889431 | −0.031590 |
| 704 | 575 | +0.002620 | 63.30% | 0.309088 | −0.006087 |
| 726 | 214 | +0.004733 | 68.69% | 0.315986 | −0.005581 |
| 1006 | 55 | +0.011462 | 72.73% | 0.508418 | +0.013263 |

8/8名受试者的平均包络误差增加；分别查看三个seed，平均三个SHIFT后24/24个“受试者×seed”组合也同向。H2错位与固定GN两个条件下，8人的平均包络变化同样全为正。重复seed用于检查训练随机性的稳定性，独立受试者分母仍为8。

670只占79/2310=3.42%的窗口，却贡献全体RR均值差中的+0.038381 bpm；全体净差为+0.035174 bpm，即109.12%的净增量来自670，其余7人合计抵消约0.003206 bpm。因此RR改善/退化不能推广成所有受试者共有的效果。

## 4. 670为何对RR干预特别敏感

谱诊断读取已保存的参考与三个seed的常规A0预测，对每个180秒窗口的9个20秒局部窗计算呼吸带内分离局部峰的次强/最强功率比。比例越大表示谱峰竞争越强；它是连续描述量，不是预设“双峰病例”标签。

670的参考RR估计相邻变化均值为5.401 bpm，其余受试者为0.499–1.024 bpm；参考与预测的谱峰竞争均值分别为0.371和0.369，均为8人中最高。其FULL RR MAE也已达到6.427 bpm，说明它在干预前就是RR重建较困难的受试者。参考RR估计的变化同时可能受谱峰切换影响，不能全部解释为真实生理节律的快速变化。

在670的79窗内，H-SHIFT引起的RR误差变化与诊断变量的Spearman描述如下：

| 变量 | 与RR误差变化的相关 |
|---|---:|
| 常规预测谱峰竞争 | +0.503 |
| 参考谱峰竞争 | +0.226 |
| 参考相邻RR估计变化 | −0.364 |
| 既有transient_motion_ratio | +0.387 |
| rate_confidence_score | −0.260 |

按预测谱峰竞争从低到高作事后四分位分组，四组RR误差增量依次为+0.223、+0.749、+1.188、+2.332 bpm，对应窗口数20、20、19、20。已有`transient_motion_ratio`最低/最高分组的增量分别为+0.354/+2.000 bpm。`rate_confidence_level=medium`的74窗增量为+1.207 bpm，`high`的5窗为−0.137 bpm；后者分母很小。

这些结果更支持“原本存在较强谱峰竞争的窗口，对高频条件错位更敏感”。单纯用“参考节律变化快”解释额外退化并不符合窗口内方向：RR变化最低四分位的增量为+1.832 bpm，最高四分位为+0.616 bpm。

质量标签按原始含义列示：`rate;phase;event;waveform`为62窗，增量+1.519 bpm；`rate;waveform`为17窗，增量−0.326 bpm。这些字符串不是有序质量分数。在670中，`transient_motion_ratio`与`posture_transition_ratio`逐窗完全相同，`amplitude_reliable_ratio`为其互补，不能视为三份独立证据。

**解释边界：** 常规保存预测使用batch128，机制评价使用batch8；前者的谱峰竞争只能作为辅助协变量。当前结果没有逐窗证明“干预使某一谱峰胜出”，也没有独立分离谱峰竞争、质量和基准难度的因果贡献。窗口存在时间依赖，本报告不以79窗或重复seed计算独立样本显著性。全部关联和四分位分层为事后描述，未用来修改候选、阈值或checkpoint。

图：[670诊断](../../runs/cwt_apor_v2/reports/mechanism_evidence_20261003T063908Z_d5b1c2f2/subject670_diagnostics.png)。`window_rr_diagnostics.csv`覆盖2310窗，`subject670_windows_ranked.csv`列出670全部窗口，`within_subject_correlations.csv`和`quality_label_diagnostics.csv`保留所有受试者的诊断结果。
