# THO 180秒窗口呼吸波峰计数 v1

日期：2026-10-19。任务：用户授权统计完整180秒窗口、整个数据集。

## 范围与口径

- 本任务独立统计 research v2 数据索引全部窗口（含 train/val/test），仅访问 THO target 与索引。test 访问由本次用户“整个数据集”的明确范围授权，仅用于描述性呼吸计数。
- 使用 `configs/tho_research_v2.yaml` 定位索引，保留原始行身份与 split；分别汇总全索引、既有 admission 通过及未通过的窗口。
- 每窗口按现有数据加载器转换为 float32，再按 `canonicalize_numpy` 以 float64 做 0.05–0.70 Hz 整窗 FFT 投影及 soft-z 规范化。
- 复用 `resp_train.metrics.task._detect_peaks`：正峰、最短间隔142点、prominence=max(0.2 std, 0.08(P95−P5))，端点不补峰。仅计算完整 target，不作预测相关 lag 裁剪。
- `breath_peak_count` 为算法检测呼吸波峰数，并非人工逐呼吸标注真值。另存完整相邻峰间隔数量 max(count−1,0)。count/3 为每分钟计数率，不等同于谱估计 Whole RR。
- 所有窗口保留，非 dynamic 窗口显式标记；非有限输入或结果、身份或长度异常显式失败。不得因计数少或质量低另行丢弃。
- 合成边界检查发现：当前 NumPy 18000点、100 Hz 的频点126为 `0.7000000000000001`，公共 FFT 实现按 `<=0.70` 比较时排除该点。纯0.70 Hz信号因此非 dynamic，微小数值残差上的峰数不可解释。本统计保持公共算法身份，不修订历史频带；显式报告非 dynamic 数量。该边界也意味着本计数存在频带边界限制。
- 统计单位为窗口。重叠窗口计数总和有重复，不解释为整晚／整个数据集去重后的呼吸总数。不改变既有 metrics、训练、模型选择或冻结结果。

## 执行与产物

入口：`scripts/count_tho_window_breaths.py`；CPU 单线程，逐源文件读取 THO 数组，独立输出目录必须不存在。

保存逐窗口计数及峰位置、分组描述统计、受试者统计、PNG 分布图、配置、索引与实际读取数组的 SHA-256、实现来源及运行状态。源 NPZ 记录文件路径、大小与修改时间，数组哈希针对实际读取的原始 target 数组，不冒充整个 NPZ 的文件哈希。失败目录保留。

定向验证使用合成正弦、常量与非有限输入；不重跑历史实验。执行结果由独立输出目录 manifest 记录。
