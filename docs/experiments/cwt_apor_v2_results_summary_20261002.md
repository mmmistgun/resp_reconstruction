# CWT-APOR/A0时频表示实验：结果总览

日期：2026-10-02。协议：`cwt-apor-v2-20261001`。状态：20配置×3seed训练/validation、固定60-checkpoint research-test及3seed×18条件机制分析均完成并关闭。

**本轮结果显示，CWT设置会改变节律与波形形态重建的取舍。H-only在本轮test取得最低的平均Local RR误差；更宽频带或更细时间分辨率并不带来各指标的一致提升。机制分析更稳定的发现是：高频条件的时间对应关系影响包络重建，这种影响在固定GN和exclude670视图中均保留；RR的干预响应则高度依赖受试者。**

## 1. 研究范围与统计口径

主模型为APOR/A0：D96、六层双向Mamba2、140个patch、五点条件取样、H65条件末端、双支有界FiLM及Hann重叠合成。A0基准CWT为μ=13.4、voices=12、0.5秒池化、上限8 Hz，表示尺寸97×360。

数据为train 10141窗/32受试者、validation 2675窗/7受试者；test full为2310窗/8受试者。预定敏感性视图exclude670为2231窗/7受试者，subject670为79窗/1受试者。下文默认先对每seed的窗口取均值，再对三个seed取均值；受试者等权结果另行列出。seed SD不是独立受试者层面的置信区间。

### CWT参数：存在取舍，没有单调的分辨率收益

μ=6、voices=24的test Local RR为0.60805，包络MAE为0.14503；μ=20、voices=24的test Local RR为0.68750，包络MAE为0.13937、PCC为0.88263。前者偏向节律误差，后者偏向包络/PCC。增加voices或改变μ未形成跨指标一致、单调的收益。

Validation上Local RR最低的是4 Hz配置；test上最低的是H-only。这是预定完整矩阵的结果描述，不据test排序更换checkpoint或追认一个新的验证集选择。

### 时间池化：0.25秒未改善RR，1秒体现节律/包络取舍

相对A0，0.25秒池化使test Local RR均值增加约4.4%，三个seed均变差；PCC也在三个seed中下降。其包络均值略低，但仅1/3 seed改善。

1秒池化使test Local RR均值降低约4.5%，2/3 seed改善；整段RR误差三个seed均改善。但包络误差三个seed均增加，均值增加约2.0%。

预定高变化分层也没有支持“更细池化必然更好”：full视图RR高变化层（690窗）Local RR为A0 1.55333、0.25秒1.56997、1秒1.54759。exclude670相应层（614窗）为0.96415、0.99690、0.97172，1秒的整体RR收益并未延续到这一分层。

### 频带上限：扩大到20 Hz更偏向RR，形态指标付出代价

4 Hz配置test Local RR比A0降低约2.1%，三个seed均改善；包络误差、全局包络调制误差和PCC则均在三个seed中变差。

20 Hz配置test Local RR均值降低约3.3%，但包络轨迹MAE增加约6.4%、全局包络调制误差增加约9.7%，PCC由0.88182下降至0.87650；这三项形态指标三个seed均变差。频带扩大并未带来整体重建质量的一致改善。

### L/H训练对照：高频条件可支持节律重建，简单互补增益未成立

H-only的test Local RR比A0降低约6.5%，整段RR误差由0.66663降至0.62071，两个RR指标均为三个seed一致改善。exclude670的Local RR由0.44564降至0.41115，三个seed也均改善。

L-only与A0的Local RR接近，但包络MAE和PCC在三个seed中均较差。H-only的包络均值也略高于A0，full PCC均值接近A0。因此，H-only支持有效的节律重建；L+H并未在全部指标上统一优于两种单带配置。

这些是分别训练后的适应性结果。后文的固定模型干预回答A0已经学会使用什么，二者不能互相替代。

## 4. 固定checkpoint机制分析

本部分以机制流程自己的batch8 FULL/NAT为配对参考；它的数值不能与常规batch128 test混作同一基准。三个seed共6930次同batch普通前向/FULL逐窗比较，最大波形差均为0；FULL/NAT与FULL/FIXED五项主指标逐窗相同。三视图汇总均完整，具体证据见[机制完成记录](cwt_apor_v2_mechanisms_results_20261002.md)。

### 更稳定的结果：高频时间对应关系影响包络

- 对H=(0.8,8] Hz做三个预定共同时间平移，full包络MAE增加2.27%–2.41%；exclude670仍增加2.01%–2.18%。每个SHIFT在三个seed中均增加误差。
- H2=(2,8] Hz对应为full增加1.49%–1.60%、exclude670增加1.58%–1.68%。
- 固定GN后，H错位的包络增幅仍为full的2.29%–2.43%、exclude670的2.03%–2.20%。

这说明高频条件的时间对应关系具有包络重建功能；固定GN后影响保留，单纯GN重新计算统计不足以解释该现象。当前干预没有单独识别整体强度与跨尺度相对结构的贡献。

### RR干预效应主要集中在受试者670

full视图中，H窗口均值替换使Local RR增加4.71%，H错位使其增加4.91%–5.92%。但exclude670中，均值替换仅增加约0.064%，H错位反而使Local RR降低约0.59%–0.95%。

subject670的FULL Local RR为6.42694 bpm，H窗口均值后为7.31421，H错位后为7.44867–7.62583。因此，完整视图的RR退化主要由670贡献；包络响应比RR响应具有更一致的跨视图方向。

TF-S7已保存预定案例的gamma/beta、Z/Z_prime、实际CWT、预测与参考曲线。此处机制结论来自完整18条件配对指标；尚未将效果归因到某个FiLM通道或单独的乘性/加性分支。

## 5. 本轮实验支持的结论

1. **CWT表示选择改变优化取舍。** 更密尺度、更细时间池化、更宽频带都不是普遍改善项；需要同时查看节律误差和形态指标。
2. **高频条件包含可用于呼吸重建的信息。** H-only训练取得稳定的RR改善，而固定A0的高频错位产生稳定的包络损失；两条证据分别来自重新训练对照和固定模型功能干预。
3. **A0的高频时间对应关系对包络更具一致性作用。** 该效应在exclude670和固定GN后仍保留；RR效应则呈明显受试者差异。
4. **目前没有一个配置在五项主指标和不同受试者权重下统一占优。** 本轮的价值在于揭示表示与重建目标之间的关系，而不只是提供一个test排序。

TF-S1的校准、train/validation信号统计与分层阈值已按原定义完成并复用。压缩前后非线性预处理比较不在本轮证据范围；本文不据输入频带名称推断生理来源。描述性test比较保留完整矩阵和所有预定视图，不将三个seed视为三个独立临床队列。
