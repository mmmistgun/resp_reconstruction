**均匀patch池化主要损害Whole RR。** UniformPatchPool−B的Whole RR为+0.032255±0.024646，3/3 seed变差；Local RR为+0.008944，低于均值门槛。包络轨迹误差有所下降，属于指标取舍。

## 3. CWT参数敏感性

20份CWT表示保持同一M4-S1结构。相对B，19个参数变体的Local RR均值差均小于0.01，范围约为 **−0.004440至+0.006001 bpm**。这些变体在另外四项窗口加权主指标上也没有达到0.01的均值改善。

| 子矩阵 | 主要观察 |
|---|---|
| μ×voices（3×4） | Local RR均值范围0.518911–0.526269；μ=13.4、voices=4最低，但对B仅改善约0.00214。六个预设Local RR交互项绝对均值最大0.004597，均小于0.01。 |
| 时间池化 | 0.25秒与1秒的Local RR分别0.522502、0.521477，B为0.5秒的0.521053。0.25秒相对1秒的Whole RR增加0.012619±0.025336，2/3 seed变差。更细时间池化未带来整体收益。 |
| 名义频率上限 | 0.8/2/4/8/12/20 Hz的Local RR均值分别0.527055/0.523044/0.522807/0.521053/0.520764/0.520495；全跨度变化仍不足0.01。扩展到20 Hz的Whole RR相对B增加约0.0140。 |
| H/L/完整频带 | H-only Local RR为0.516614，是CWT参数组最低值；相对B改善0.004440。H−C_0p8为 **−0.010441±0.009132**，3/3 seed改善，但仅1个seed的幅度达到0.01。 |

H-only相对低频-only达到Local RR均值门槛，不代表H-only相对完整B或NoTF具有同等幅度的优势。更密的尺度、更细的时间池化或更高的频率上限，均不能仅凭表示分辨率推定质量更高。完整Q网格、频带相邻比较及μ×voices交互保存在 `paired_summary.csv`、`effect_summary.csv` 及对应宏平均表中。

## 4. 池化位置的2×2效应

四臂为B（评分和值位置均开启）、NoPoolPosition（均关闭）、ScorePositionOnly及ValuePositionOnly。

联合移除位置后，Whole RR增加 **0.023756±0.011657**，3/3 seed均变差且超过0.01；Local RR增加 **0.010911±0.013581**，2/3 seed变差。宏平均Local RR增加0.021584，3/3 seed均变差且超过0.01。

| 条件效应：开启指定路径减去关闭 | Whole RR Δ±SD | Local RR Δ±SD |
|---|---:|---:|
| 值路径关闭时，开启评分位置 | +0.009820±0.018608 | −0.001588±0.002303 |
| 值路径开启时，开启评分位置 | −0.018282±0.008238 | −0.005339±0.016980 |
| 评分路径关闭时，开启值位置 | −0.005474±0.015258 | −0.005572±0.005616 |
| 评分路径开启时，开启值位置 | −0.033576±0.012220 | −0.009323±0.015633 |

Whole RR的值路径平均主效应为−0.019525±0.011280，3/3 seed为负；评分路径平均主效应为−0.004231±0.011968。Whole RR交互 `B−ScoreOnly−ValueOnly+NoPosition` 为 **−0.028102±0.015979**，3/3 seed为负；全局包络调制误差的交互也为负（−0.016495±0.014395，3/3）。Local RR交互为−0.003751±0.018652，seed方向混合。

这些结果支持Whole RR上的组合效应：一条位置路径的作用随另一条路径开关而改变，不能将两条路径的增量当作独立、固定的加性贡献。当前三seed效应方向不构成统计显著性证明。全部五指标的条件效应、主效应和交互均已导出。
