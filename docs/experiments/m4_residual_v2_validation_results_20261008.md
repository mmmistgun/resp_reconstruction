# M4-v2 单投影时频残差 validation 结果

截至 2026-10-08，固定 6 臂 × 3 seed 的 18-cell train/validation 及完整汇总已完成并关闭。本文件承接当前阶段状态；模型、数据、优化、预设比较和选点合同见 [执行协议](m4_residual_v2_protocol_20261007.md)。原协议与源码保持冻结身份。

本轮最一致的结构证据是显式 BiMamba2 的增量：移除后五项主指标在三个 seed 均变差。Query RMSNorm 没有呈现明确的主指标收益或更低的 Local RR seed 波动。CWT residual 分支的结果仍体现指标取舍：A0 的 Whole RR 与包络轨迹均值优于 NoTF，NoTF 的 Local RR、global modulation、PCC 及 subject-macro Local RR 均值更优。

递增链按协议预设分别比较 TF information、content attention 和 physical coordinates：

|---|---|---:|---:|---:|---:|---:|

- **CWT residual 的整体增量尚未成立。** A0 相对 NoTF 的 Whole RR 与包络轨迹均值改善，但都为 2/3 seed；NoTF 的 global modulation 在 3/3 seed 更低。A0 在 Local RR/PCC 的均值未超越 NoTF。均匀 TF residual 也呈现包络轨迹改善、global modulation 变差的取舍。
- **Attention 的收益依指标而定。** A0 相对 MeanTF 的 Whole RR 和 PCC 在 3/3 seed 改善，幅度分别为 0.009871 bpm 和 0.000974；Local RR 均值略差。content-only attention 相对 MeanTF 的 Local RR 和 global modulation 在 3/3 seed 变差，因此不能将 content-dependent 读取概括为全面改善。该比较同时改变 Q/K/V 参数化，遵循协议定义。
- **坐标 bias 在窗口加权口径有一致的局部节律与全局包络收益。** A0 相对 S2 的 Local RR、global modulation 在 3/3 seed 改善；其他指标方向混合。S2 仍保留物理窗口对齐，这一比较只检验显式 bias。
- **Query RMSNorm 暂无采用依据。** S1 的 PCC 在 3/3 seed 略低，四项主指标均值较 A0 差，包络轨迹仅略优；Local RR seed SD 为 0.004413，高于 A0 的 0.001232。不能据此宣称其改善训练稳定性。
- **保留 BiMamba 的 validation 证据最强。** A3 五项主指标在 3/3 seed 均变差；Local RR 增加 0.099061 ± 0.001684 bpm，PCC 下降 0.035098 ± 0.006482。该结论对应当前 validation，独立于前序模型的 test 表现。
