# M4 linear fusion 单/双投影 validation 结果

截至 2026-10-19，三个新增单投影 seed 的 train/validation，以及与冻结双投影基线组成的完整六 cell 汇总，均已完成并关闭。双 GPU 后台任务 `j-dij7ip` 退出码为 0，失败 attempt 为 0。执行合同见 [实验协议](m4_linear_fusion_v1_protocol_20261019.md)，基线选择见 [简化基线决策](m4_simplified_baseline_decision_20261019.md)。

**按预先确定的窗口加权 0.01 判据，本轮 validation 支持单投影作为进一步简化候选：Whole RR 误差在三个 seed 上均改善超过 0.01 bpm，其余四项主指标的跨 seed 均值变化均小于 0.01。受试者宏平均下，Local RR 和全局包络调制误差上升超过阈值，说明收益存在受试者差异。**

## 完成状态与核验

Whole RR 在三个 seed 上均达到改善阈值；Local RR 和 PCC 三个 seed 均略有改善。全局包络调制误差三个 seed 均上升，其中 seed 20260811 的 +0.014819 达到变差阈值。因此“其余四项均值无明显差异”不表示每个 seed 的差值都小于 0.01。

## 结构判断与证据范围

窗口加权判据支持移除额外融合投影，且 Whole RR 的改善方向在三个 seed 上一致。两个连续 affine 的函数可以合成，但本轮还改变了零初始化位置及优化参数化，结果归因于这一完整结构变更，不能解释为额外 affine 在任何训练设置下都无用。

本阶段结论仅来自 train/validation。当前记录将 L1 列为简化候选；research-test 尚未执行，须由匹配专项协议与当次授权开放。
