# M4-v2 固定 checkpoint research-test 结果

截至 2026-10-08，6 臂 × 3 seed 的固定 18-checkpoint research-test 及完整汇总已完成并关闭。执行合同见 [research-test 协议](m4_residual_v2_research_test_v1_20261008.md)，训练与选点依据见 [validation 结果](m4_residual_v2_validation_results_20261008.md)。本文件承接当前阶段状态，源码与原协议维持冻结身份。

本轮形成明确的指标取舍：A0 在窗口加权的包络轨迹与 PCC 上具有最佳三 seed 均值，NoTF 在 Whole RR、Local RR、global modulation 以及 nDTW 上具有最佳均值。A0 与 MeanTF 的 RR 接近；显式坐标和 BiMamba 的形态指标收益在三个 test seed 均保持，但其窗口加权 RR 收益未保持。Query RMSNorm 在三个 seed 均使两项 RR 误差变差。

## 数据与统计口径

固定 test 为 2310 窗口/8 人，seeds 20260811/20260812/20260813。18 个 checkpoint 全部按完整 validation Local RR 严格最小、并列最早规则选择，epoch 与专项协议一致。test 与 development 受试者隔离由运行入口检查。

以下主表与辅助表先按每个 seed 的有效窗口求均值，再报告三 seed mean ± sample SD（ddof=1）。同 seed 配对；三个 seed 共用同一 test 人群。该集曾用于研究开发并影响本轮设计，证据角色为 **reused research/development evidence**，本轮为固定矩阵跨 split 复核。

全部 cell 的五项主指标分母均为 2310，样本顺序与 target 资格一致；joint 与分层包络 Spearman 预测退化计数均为 0，Local RR prediction-valid 和 joint-target-eligible 比例均为 1。本次仅核验与汇总已保存产物。

## 跨 split 解读与结构收敛

- **A0 相对 NoTF 的增量集中于包络轨迹与 PCC。** test 两项在 3/3 seed 改善；两项 RR 均值与 NoTF 相比变差。NoTF 的 subject-macro Local RR 同样更低。以节律误差为主要目标时，当前证据更支持 NoTF；保留 A0 应表述为特定形态指标收益及其 RR 代价。
- **Attention 相对 MeanTF 的 RR 增量很小。** A0−A2 的 Whole RR 为 -0.001154、Local RR 为 -0.000704 bpm，seed 方向混合；A0 的包络轨迹与 PCC 则在 3/3 seed 改善。均匀 TF residual 相对 NoTF 在 3/3 seed 降低包络轨迹误差，但也在 3/3 seed 增加 Local RR。TF representation 本身已呈现节律与包络取舍。
- **物理坐标的节律收益未跨 split 保持。** validation 中 A0 对 S2 的 Local RR 在 3/3 seed 改善，test 中均值增加 0.049505 bpm、2/3 seed 变差；test 的包络轨迹、global modulation 和 PCC 则在 3/3 seed 改善。S2 保留相同对齐窗口，该对照只检验显式频率/时间 bias。
- **Query RMSNorm 没有采用依据。** test 中 S1 的 Whole RR 增加 0.017166 ± 0.003064 bpm、Local RR 增加 0.012784 ± 0.006097 bpm，均在 3/3 seed 变差；其余主指标差异很小。两项 RR 的 seed SD 也高于 A0。
- **BiMamba 的形态收益跨 split 保持，RR 结论依赖 split 与权重。** A3 的 test 包络轨迹、global modulation 与 PCC 在 3/3 seed 变差；PCC 平均下降 0.025498 ± 0.001732。A3 的窗口加权 Local RR 均值却低于 A0 0.049432 bpm，validation 的稳定节律收益未保持；受试者等权 Local RR 则仍以 A0 较低。A3 仍含 CWT 支持、整窗 GroupNorm 和连续 CNN 邻域，不能将其称为严格 1 秒信息模型。

本轮结果支持结束以单项均值驱动的结构扩展，完整保留 NoTF 与 A0 的权衡作为模型选择依据。A0 尚未建立跨指标整体优势；旧 M4 的 Whole RR 均值优势也不能直接转移到采用新参数化与初始化合同的 M4-v2。
