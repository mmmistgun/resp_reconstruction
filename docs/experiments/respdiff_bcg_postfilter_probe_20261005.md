# RespDiff-BCG：后处理滤波与继续训练判断

2026-10-05，针对用户关于手动滤波、尖峰来源、是否继续训练及 checkpoint 选择的提问，检查已有 epsilon-only 输出、训练日志和 checkpoint 元数据。执行的是保存输出上的小规模 CPU 诊断；未调用模型、启动 GPU、继续训练或访问独立测试集，正式结果保持原样。

## 使用的 checkpoint

epsilon-only 与 SNR FFT 均使用第 **6400 次 optimizer update** 的 `final.pt`，`selector=final_update`，优化器保存的最终 lr 为 `1e-6`。训练结束后才执行 validation，未按 validation 最优分数选择 checkpoint。当前产物没有供回选的一系列中间模型。

## 滤波的预先定义与范围

来源为 `runs/respdiff_bcg_loss_repair_v1/epsilon_only_seed20260811_r01` 的保存 prediction/reference。按保存顺序均匀间隔固定取 64 个父窗口，另加已知异常 row 10382、12637，共 66 个；两组分别报告，不把异常样本混入 64-window 汇总。

一次性定义以下对照：原保存输出、与公共评价一致的 0.05–0.70 Hz FFT 投影、20 Hz 上四阶 1 Hz Butterworth SOS 零相位滤波（sosfiltfilt）、20 Hz 上 3 点/5 点中值滤波（reflect 边界）。低通及中值处理后，仍用原公共 Fourier 插值回 100 Hz、同一 reference 和公共评价函数。

入口 `scripts/probe_respdiff_bcg_postfilters.py`；完成产物位于：

`runs/respdiff_bcg_loss_repair_v1/postfilter_probe_epsilon_only_20261005_r02`

其中 `plan.json` 记录选样和滤波参数，`summary.csv`/`per_parent_metrics.csv` 记录诊断指标，`filter_examples.png` 展示两个异常窗口，`manifest.json` 记录来源和产物。r01 在 NumPy 反向 stride 转 Torch 时失败，已保留 failure；修正仅整理数组内存布局，r02 使用相同预定义对照完成。

这是后处理候选的诊断，不是新的全量 validation 结果，也没有据此切换正式模型输出。若后续采用滤波，需要明确新的输出方法身份。

## 固定等距 64-window 结果

| 处理 | Whole RR MAE ↓ | Local RR MAE ↓ | 包络轨迹 MAE ↓ | 全局调制误差 ↓ | PCC ↑ |
|---|---:|---:|---:|---:|---:|
| 原保存输出 | 1.984586 | 2.340076 | 0.429179 | 0.800449 | 0.456503 |
| 公共频带投影 | 1.984586 | 2.340076 | 0.429179 | 0.800449 | 0.456503 |
| 1 Hz 零相位低通 | 1.984575 | 2.340074 | 0.429104 | 0.800202 | 0.456713 |
| 3 点中值 | 1.939639 | 2.331363 | 0.425709 | 0.790774 | 0.461615 |
| 5 点中值 | 1.983306 | 2.330498 | 0.423984 | 0.788509 | 0.466566 |

公共评价已对 prediction 做呼吸频带投影 B 和幅度归一化 S。再次施加相同 B，在理想算术下满足 `B²=B`；本次主指标最大差仅 `7.11e-15`。因此相同频带的额外滤波不能带来新的有效信息。1 Hz 低通能降低原始峰值，却几乎不改变公共指标。

3/5 点中值对窄尖峰有作用；本次 64-window 上收益较小，不能据此宣称全量重建已经解决。两种中值并非每项指标都同序，没有选择逐样本最优处理。

## 两个异常窗口

两窗口的平均 PCC 从 0.3068 提至 3 点中值的 0.5228、5 点中值的 0.5238；该组为刻意选择的异常样本，不代表总体增益。5 点中值后的两窗口最大绝对幅值仍可达到约 288.67。

图中 row 10382 主要是极窄针状点，中值处理能明显压低；row 12637 则在窄峰下还存在较宽的高幅脉冲，中值去掉最高点后，呼吸频带内的脉冲和时序偏差仍保留。这解释了为什么“曲线看起来平滑”不等于波形重建正确。

## 尖峰来源：已证实部分与尚待证实部分

此前对原版 checkpoint 的 GPU 诊断已零误差复现输出，并直接记录：t=49 的 epsilon 残差约 0.8613，在 alpha_bar≈2.08e-7 下被放大约 2193 倍，第一次 x0 估计即达到约 -1889。该直接链条见 [固定 checkpoint 诊断](respdiff_bcg_checkpoint_diagnostic_20261004.md)。尖峰已存在于 20 Hz 片段/父窗口输出，并非 100 Hz 插值首次引入。

当前 epsilon-only 已去掉 FFT 项，仍存在尖峰，所以 FFT 不是唯一成因。它沿用同一极小终点 alpha_bar 的 epsilon 参数化及六步 DDIM。保存输出中的 row 10382 残余峰仍在 12.75 秒，幅值 -988.00，对应同一初始高斯噪声 -5.3223；row 12637 的峰在 6 秒，幅值 1301.39，对应初始噪声 3.7980。这是机制延续的线索；本次未重新前向追踪新 checkpoint，不能把旧版每一步的数值直接当作新版的已测因果链。

## 是否继续训练

epsilon-only 的训练记录：

| updates 区间 | 平均 noise MSE | lr |
|---|---:|---:|
| 1001–1500 | 0.027277 | 1e-4 |
| 3001–3500 | 0.023557 | 1e-4 |
| 4001–4480 | 0.022636 | 1e-4 |
| 4501–5000 | 0.019941 | 1e-5 |
| 5001–5500 | 0.019929 | 1e-5 |
| 5501–6000 | 0.019898 | 1e-5 |
| 6001–6336 | 0.019842 | 1e-5 |
| 6337–6400 | 0.019477 | 1e-6 |

SNR FFT 的末期轨迹接近。最后约 1900 步已基本平台化，4501–5000 与 6001–6336 的 noise MSE 均值差约 0.5%；最后 64 步样本数更少，不宜据其较小均值直接推断显著下降。

实际训练共处理 409579 个片段，相当于 131833 个训练片段集合的约 3.11 遍。遍历次数较少不等同于已证明需要继续训练，平台化的训练 loss 也不能单独证明已经收敛；当前只有最终 validation，没有验证曲线来判断更长训练是否改善重建。

因此暂不建议直接沿用已经降到 1e-6 的学习率无明确预算地续训来解决尖峰。优先核对新 checkpoint 的高噪声步及残余宽脉冲；若要检验训练时长，应使用明确的新预算/学习率日程和独立输出，保持同一评价规则进行对照。当前未执行继续训练或新的 GPU 诊断。
