# 呼吸率与SA窗口分层结果总报告：H-only、M4、IEWT

更新日期：2026-10-07（Asia/Shanghai）。状态：**全部分析完成并关闭**。本文是本系列结果、口径和来源的统一入口。

三种方法在同一批2310个research-test窗口上评价。H-only与M4在慢呼吸、12–20 bpm参考范围及两个SA组别中的五项窗口均值均优于IEWT；快呼吸区间则呈现指标间取舍：IEWT的Whole RR误差最低，H-only的Local RR、包络轨迹和调制误差最低，M4的PCC最高。

## 1. 统一口径与模型身份

| 项目 | 固定口径 |
|---|---|
| 数据 | 既有research/development test，2310窗、8名受试者，每窗180秒、100 Hz |
| 呼吸率分组 | THO参考Whole RR：慢 `<12`、参考范围 `12≤RR≤20`、快 `>20 bpm`；使用未舍入值 |
| 参考RR算法 | 同源THO波形经既有标准化，60秒谱窗、30秒步长、中位功率谱及峰值插值，形成180秒窗口Whole RR |
| SA分组 | 阻塞性、中枢性、混合性暂停或低通气事件与窗口正时长相交即为含SA；仅端点接触不算，其余为无SA标注事件 |
| 汇总 | 各实例内对窗口算术平均；H-only/M4再对三个seed计算均值和sample SD（ddof=1）；IEWT报告确定性单次均值 |
| 指标 | Whole RR绝对误差、Local RR MAE（单位bpm）、包络轨迹MAE、全局包络调制误差、lag-aware signed PCC；前四项越低越好，PCC越高越好 |
| 分母 | 所有模型、实例、分组的五项主指标有效分母均等于对应窗口数；RR与SA分别分析，RR组保留暂停窗口 |

成人静息参考界限依据见 [Nursing Skills呼吸评估](https://www.ncbi.nlm.nih.gov/books/NBK593192/)。在本数据中，这些区间描述THO谱估计的呼吸率，不直接用于睡眠期临床异常诊断。

| 方法 | 实验身份 | Seed／checkpoint |
|---|---|---|
| H-only | CWT-APOR v2，条件频带 `(0.8,8] Hz`，H65 | 20260811/20260812/20260813；epoch 8/13/22 |
| M4 | Patch-aligned TF-Mamba的P1-Full-Add：1秒patch、W-full CWT、对齐cross-attention、零初始化线性residual-add、六层BiMamba2 | 同上三seed；epoch 25/5/8 |
| IEWT | protocolized Python IEWT，零相位；输入为既有状态对齐segment soft-z宽带BCG | 确定性单次；seed SD未定义 |

学习模型checkpoint均由原完整validation Local RR selector固定。IEWT实现未建立MATLAB逐点等价性。

全量均值中，M4的Whole RR误差最低，H-only的另外四项指标最佳。三种方法的原评价分别完成于不同实验，比较基于相同窗口、参考和指标口径。
