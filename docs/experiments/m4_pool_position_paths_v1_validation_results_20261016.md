**评分路径。** 在值路径开启时，A 相对 D 的包络轨迹误差在 3/3 seed 上增加，PCC 在 3/3 seed 上降低；Local RR 则为 2/3 seed 改善，平均下降 0.002093 bpm。值路径关闭时，C 相对 B 的 Local RR 为 1/3 seed 改善。评分位置的收益依赖指标和另一条路径。

**值路径。** 评分关闭时，D 相对 B 的包络轨迹误差在 3/3 seed 上降低（均值 −0.003796），但 Whole RR 在 3/3 seed 上升高（+0.016766 bpm）。评分开启时，A 相对 C 的全局包络调制误差在 3/3 seed 上降低（−0.020451），受试者等权口径亦为 3/3 seed。值路径对调制保真的贡献比其对 Local RR 的贡献更一致。

## 交互效应

交互定义为 `I=A−C−D+B=(A−D)−(C−B)`，是另一条路径开关导致的条件效应变化。对误差指标，正交互表示联合条件的误差高于加性参照 `C+D−B`；该参照是代数比较量。

| 指标 | I mean ± SD | 逐 seed 符号（11/12/13） |
| --- | ---: | --- |
| Local RR | −0.003311 ± 0.004628 | − / + / − |
| Whole RR | +0.006723 ± 0.039637 | + / + / − |
| 包络轨迹 | +0.013985 ± 0.009988 | + / + / + |
| 全局包络调制 | −0.013660 ± 0.016896 | − / + / − |
| PCC | +0.002512 ± 0.008711 | − / − / + |

最一致的是包络轨迹的正交互：逐 seed 为 **+0.019719、+0.002452、+0.019783**。单独加入值位置时 D−B 为负，评分已开启时 A−C 的均值转正；单独加入评分位置时 C−B 的均值为负，值已开启时 A−D 在三个 seed 上均为正。因此两条位置路径的包络轨迹收益不能按各自单独效果直接相加。

Local RR 的交互为 −0.007741、+0.001492、−0.003683 bpm，方向混合。全局包络调制的交互均值为负，但也只有 2/3 seed 同向；这些结果不足以主张稳定的 RR 或调制协同增益。

## 结构判断

评分位置的稳定增量尚未建立，其 Whole RR 与 PCC 的平均代价在两种聚合方式下均为三 seed 同向。值位置值得作为包络保真相关的结构保留候选，尤其 A−C 对全局包络调制的改善。

候选选择需要区分目标：**B 更适合 RR 优先的简化方向；D 是波形相关与包络轨迹取舍的重要候选。** D 相对 A 的 PCC 在 3/3 seed 更高、包络轨迹误差在 3/3 seed 更低，但其 Local RR 均值较 A 高 0.002093 bpm，Whole RR 相对 B 在 3/3 seed 更差。A 的全局包络调制均值最低，但 A−D 只有 1/3 seed 改善，不能把这一均值优势写成评分路径的稳定贡献。C 的包络轨迹均值优势同时伴随较差的 PCC 和全局包络调制。

这些效应来自不同结构各自重训练并按相同 validation 规则选点后的系统表现。当前阶段完成了评分/值路径的描述性分解；阈值未设，独立测试集尚未评价，不作等效、显著性或独立泛化结论。
