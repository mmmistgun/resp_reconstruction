## 结构判断

在保持频率 bias 和其余结构的直接对照下，当前 validation 没有显示交叉注意力 Δt 时间 bias 对五项主指标的均值贡献达到 0.01。按本次判据，倾向将 A1 作为下一步的简化候选；保留时间 bias 尚缺少本轮性能依据。

这个结论针对交叉注意力中的 `bt(Δt)` 项。频率 bias、局部时频读取的物理对齐和时域注意力池化均保持存在，不能据此推断其他模块也可移除。

阈值在运行前固定，采用各指标原生数值单位；“均值无明显差异”是描述性判定，不是统计等效证明。三个 seed 共用同一 validation 人群，该集也用于选点。本轮尚未进行 research-test，结论限定于当前 train/validation。原始 M4 模型与历史冻结结果保留其身份。
