## 对 linear fusion 的判断

当前建议保留额外 `fusion.projection`：移除仅减少 9,312 参数（约 0.882%），而完整三 seed 的 test Local RR、Whole RR 均值均出现超过既定阈值的退步，validation 的 RR 收益未跨 split 保持。

两个连续 affine 在函数上可合并，但本次还改变了零初始化位置和优化参数化。结果支持“当前训练与选点方案下，直接替换为单投影尚不稳妥”，不证明双投影在函数表达上必不可少，也不证明单投影在所有训练方案下都更差。任何后续不同初始化或训练策略都应作为独立实验，不能利用本轮 test 重选当前 checkpoint。

该 test 已参与研究开发，证据角色为 reused research/development evidence；0.01 是描述性判据，三个 seed 不能构成统计等效或稳定泛化的证明。
