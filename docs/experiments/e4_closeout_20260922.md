# E4 尺度聚合与频带机制检查：结项报告

日期：2026-09-22。状态：**既定实验已完成，进入论文证据整理；E4 当前训练、评价与机制检查阶段关闭。** 本记录为 E4 当前状态入口，执行期协议和锁继续保存各阶段定义与原始身份。

配套 [性能、代价与机制证据数据集](e4_closeout_data_20260922/README.md) 保存完整精度 CSV、字段与统计口径说明、来源身份及可复核整理入口。

## 1. 结项判断

**本轮五个聚合候选没有形成跨 validation/test、跨属性的稳定整体收益，继续保留 W0 为既定论文主模型。机制检查支持聚合器学到了温和且部分有用的重加权，也支持 R3 幅度时间结构对当前模型的任务价值。**

这回答了三个不同层次的问题：

1. **结构选择：**四区域残差融合、静态尺度加权、尺度注意力、频率感知注意力和逐通道区域加权，均完成三 seed 训练和所选 checkpoint 的 test 评价；当前结果不支持以其中一个候选替换 W0，也不能证明尺度均值普遍最优。
2. **checkpoint 内功能：**权重总体接近均匀，但对聚合特征产生约 2%–4.4% 的相对修正；恢复均匀后部分属性变差。结构间收益不足与模块未学习是不同判断。
3. **R3 时序信息：**固定 W 分支 GN 后，破坏 R3 时间对应仍稳定损害包络轨迹与波形相关，支持其幅度起伏中存在被模型利用的呼吸相关信息。呼吸率结果存在受试者差异，生理来源仍未确定。

## 4. 聚合器学到了什么

详见 [频带编码与聚合干预结果](e4_band_encoding_aggregation_results_20260919.md)。四个 v2 候选相对均匀权重的 TV 约 1.98%–3.24%；实际聚合修正 RMS / 原均值特征 RMS 依次约为 2.027%、4.193%、4.428%、2.083%。说明“接近均匀”可以与可测的特征变化同时成立。

在同一 checkpoint 内恢复均匀后，包络轨迹误差分别增加 2.916%、0.609%、0.629%、0.286%，四候选各自均为三个 seed 同向。静态加权的证据最清楚；逐通道区域加权则同时出现 PCC 改善的属性取舍。因此可支持局部功能收益，不能据此声称候选整体优于 W0。

两种入口参考下，R3 的 Local RR、包络轨迹和 PCC 在五模型、三 seed 上均变差，受试者宏平均方向也保留。R3 平均权重质量仅约 25%；较大的入口干预效应与权重质量不等价。聚合前特征已经经过卷积和归一化，聚合后还经过 temporal、FiLM 和主干，不能把某个尺度权重直接命名为最终预测的重要性。

## 5. R3 时间结构与归一化控制

详见 [R3/GN 结果](e4_r3_temporal_normalization_results_20260921.md)。R3 固定为尺度槽位 `[73:97]`，分区边界约 2.080–7.996 Hz，实际中心频率约 2.191–7.996 Hz。模型输入是每半秒一个点的 CWT 对数幅度图；本实验检验其强弱起伏的时间对应。

- 固定全部四层 W-GN 后，三种时间错位仍使包络轨迹误差增加 4.35%、4.97%、4.75%，PCC 分别下降 0.004937、0.005664、0.005438；三个 seed 同向。
- 每种错位的包络轨迹退化出现在三个 seed 的全部七个 samp_id；PCC 亦表现出高度一致性。Local RR pooled 同向，但部分错位的受试者等权方向翻转，证据强度有属性差异。
- R3 平均曲线与 THO 的零滞后平均绝对周期相关由 0.289 降至约 0.101–0.104，包络相关由 0.395 降至约 0.197–0.200；三种错位均在全部七个 samp_id 上减弱。
- 完整真实 validation 的三个 FULL 控制均逐点重放；固定 GN 的实际统计与对应原 FULL 一致。时序干预造成的损失不能全部归因于 W-GN 统计变化，但卷积、跨路径一致性、FiLM 和其余主干交互仍在作用。

这支持当前模型使用了 R3 幅度时间结构中的呼吸相关信息；具体生理机制、跨人群推广及全部归一化路径的因果分解仍超出本轮证据。

## 8. 结项后的论文使用
