# CWT-APOR v2机制证据整理

日期：2026-10-03。范围：按用户要求分析已有TF-S1、FiLM案例和受试者配对结果；属于事后探索性产物分析。结果由独立目录保存，原实验、指标和完成记录保持其原有身份。

## 分析约定

1. **TF-S1**：使用既存train/validation调制PSD与关联累加表。每窗每载频去除DC后归一化PSD，先在受试者内平均，再跨受试者等权平均。调制频段为`(0,.05)`、`[.05,.70]`、`(.70,1] Hz`；这三个区间描述条件序列的变化速度。载频采用既有分段`.03–.8`、`.8–2`、`2–4`、`4–8`、`8–12`、`12–20 Hz`。关联表先合并同一受试者的质量分层累加量，再除以原有效窗口数；FULL与三个预设SHIFT在受试者、尺度层面配对。显式保存缺失原因与有效受试者数。关联使用原流程的`.05–.70 Hz`投影、零时滞及固定边界裁切；包络关联对象是投影后信号的10秒log-RMS包络。
2. **FiLM**：遍历三个seed各24个预定案例与全部18条件，核对公共Z与参考信号，保存γ/β、有效g/b、`Z′−Z`、配对潜在变化及包络误差变化。图册逐例比较FULL、H-SHIFT1自然GN及固定GN，并给出三个SHIFT总体描述。使用原导出的轨迹与逐窗指标；BF16下`Δg·Z+Δb`仅作带残差的代数诊断，不能当作精确中介分解。案例集合按每名受试者首/中/末窗口预选，不承担总体效应估计。
3. **受试者与670**：以同流程FULL/NAT为基准，先对三个SHIFT与三个seed取均值，再按原样本身份配对；同时保留逐seed、逐条件表。展示每名受试者包络/RR变化、窗口方向比例与对全体窗口加权差值的贡献。参考RR变化和质量标签来自既存表。谱峰竞争诊断只读取已保存参考/常规A0预测；复用正式整窗频带投影，对不重叠20秒局部窗作对称Hann谱，记录呼吸带内分离局部峰的次强/最强功率比及峰频率间距，使用连续量。常规预测的batch128与机制batch8不同，不能由其谱峰诊断证明某次机制干预的逐窗跳峰。相关与四分位分层仅作描述，不以重叠窗口或重复seed计算独立样本显著性。

全部输入记录SHA256；新产物保存脚本副本、环境、运行身份与完成/失败状态。非有限关键数值、样本错位、重复身份或缺少预定案例显式失败。分析不更换checkpoint，不新增训练或模型前向，不读取原始source_npz。
